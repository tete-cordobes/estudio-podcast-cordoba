## 3. LANDING PAGE - ESPECIFICACIONES

### Stack Tecnológico
- HTML5 + Tailwind CSS (CDN)
- JavaScript vanilla
- Sin dependencias externas

### Diseño Visual (Estilo The Move Miami)
```css
Colores:
- Background: #000000, #0a0a0a
- Accent: #dc2626 (rojo)
- Accent Hover: #ef4444
- Muted: #525252
- Text: #ffffff

Tipografía:
- Font: Inter (Google Fonts)
- Headlines: font-black, tracking-tight
- Labels: uppercase, tracking-wider
```

### Secciones Implementadas
1. **Hero** - "CÓRDOBA'S #1 PODCAST & MEDIA STUDIO"
2. **Social Proof** - Métricas del estudio
3. **Servicios** - Elite Content & Media Production Hub
4. **Sets/Galería** - 3 configuraciones de estudio
5. **Proceso** - 3 pasos (Consulta → Reserva → Crea)
6. **Precios** - 3 planes (Essential 50€, Professional 70€, Premium 90€)
7. **Testimonios** - Reviews de clientes
8. **FAQ** - Accordion con preguntas frecuentes
9. **Contacto** - Formulario + WhatsApp + Email
10. **Footer** - Redes sociales + Legal

### SEO On-Page Implementado
```html
<title>Estudio de Podcast en Córdoba | Tu Marca</title>
<meta name="description" content="Alquiler de estudio de podcast profesional...">
```
