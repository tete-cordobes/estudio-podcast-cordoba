# Estudio Podcast Córdoba - Landing Page

Landing page SEO-optimizada para un estudio de alquiler de podcast en Córdoba, España.

## 🎙️ Descripción

Landing page profesional para servicios de alquiler de estudio de grabación de podcast. Incluye:

- Diseño moderno dark/premium (inspirado en The Move Miami)
- Optimización SEO completa (Schema.org, Open Graph, Twitter Cards)
- Compatible con AI crawlers (llms.txt)
- Responsive con Tailwind CSS
- Core Web Vitals optimizados

## 📁 Estructura del Proyecto

```
/
├── index.html              # Landing page principal
├── robots.txt              # Configuración de crawlers
├── sitemap.xml             # Mapa del sitio
├── llms.txt                # Documentación para LLMs/AI
├── COMPACT-PROYECTO.md     # Resumen del proyecto
├── KWR-COMPLETO.md         # Keyword Research completo
└── SEO-TECNICO-GUIA.md     # Guía de implementación SEO
```
